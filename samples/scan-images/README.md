# Synthetic rice scan images

Six PNGs in three sets, generated with the built-in image_gen tool for manual
AgriVerse scanner testing. Upload one image at a time for a rice field.

| Folder | Images | Requested visual appearance |
|---|---|---|
| `set-1-healthy` | 2 | Green leaves without obvious damage |
| `set-2-disease-like` | 2 | Brown lesions and yellowing |
| `set-3-pest-like` | 2 | Chewing holes, scraping, and a caterpillar in one image |

These are AI-generated illustrations of symptoms, not verified agricultural
reference photographs. Folder names are prompt categories, not confirmed
diagnoses. Predictions may vary. Use real, independently labeled photographs
to measure diagnostic accuracy.

Full generation prompts and provenance are recorded in `prompts.json`.
